# Ndiene Tshivhase — Portfolio

Static portfolio site. Deployable to Render, Netlify, Vercel, or GitHub Pages.

## Deploy to Render

1. Push this folder to a GitHub repo
2. Go to [render.com](https://render.com) → New → Static Site
3. Connect your GitHub repo
4. Set **Publish directory** to `.` (root)
5. Click **Deploy**

That's it. No build step required.

## Local preview

Just open `index.html` in your browser — no server needed.

## Customise

- Update email in the Contact section (`mailto:your@email.com`)
- Add your GitHub URL to the GitHub button
- Swap project descriptions with real project details
